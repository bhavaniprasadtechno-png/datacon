# 01 — Prescriptive Agent Migration: validated Action objects with grounded, citation-aware confidence

**What to build:** The complete "what should we do about X?" product behavior, end to end, through the shared pipeline: user question → deterministic churn-figure computation → validated `Action` objects (title/rationale/effort/owner/expected impact/citations) computed *before* the LLM runs → KPI metrics → an explicit no-chart presentation → citation-groundedness-aware confidence → correct `Action` rendering with working citation chips in the running UI. The `Action` objects are the source of truth; the LLM only composes a user-readable explanation from them, never invents a recommendation. This replaces today's flat `actions`/`citations` payload and coarse always-high confidence. One vertical slice — backend and frontend are not split into separate tickets.

**Blocked by:** `01 — Prefactor: payloadAdapter preserves citations/correlation on structured-shape payloads` (`.scratch/payload-adapter-escape-hatch-fix/issues/01-...`). Does not depend on the Visualization Registry ticket — Prescriptive's presentation is an explicit `none` visualization, no chart type needed.

**Status:** done

- [x] Today's always-emit-3-recommendations behavior (interpolated numbers, non-conditional selection) is otherwise unchanged.
- [x] Current churn rate, at-risk account count, and target churn rate become headline KPI metrics.
- [x] **Course-corrected from the ticket's original wording**: the Presentation Planner returns `"kpi"`, not `"none"`. Re-checked `plan_visualization`'s actual rule during implementation — it only returns `"none"` when the metrics list is *empty*; Prescriptive has metrics (the churn figures), so the existing rule naturally (and correctly, consistent with Descriptive's identical metrics-only-no-chart shape) returns `"kpi"`. Forcing `"none"` would have meant special-casing around the shared rule instead of reusing it — the opposite of what this criterion asked for. No functional difference either way today (neither `"kpi"` nor `"none"` has a chart renderer registered), just a semantic-correctness fix.
- [x] Confidence accounts for citation-groundedness: `"high"` only when *every* action has at least one citation, `"medium"` otherwise (whether some or none do) — computed by Prescriptive directly, not through the Validator. Verified: the all-cited-actions test asserts `"high"`, the no-citations test and the partial-citations test both assert `"medium"` — three real fixtures, not a hardcoded constant.
