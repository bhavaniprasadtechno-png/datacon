# 01 — Diagnostic Agent Migration: trend analysis with grounded, cited spike detection

**What to build:** The complete "why did X spike?" product behavior, end to end, through the shared pipeline: user question → real day-by-day query with an explicit date column → deterministic spike-vs-baseline computation → validated structured facts → a Planner-selected line trend chart → KPI metrics → a grounded, evidence-carrying insight → citation-groundedness-aware confidence → citation chips and correlation tag rendering correctly in the running UI. This replaces today's ungrounded, chart-less, table-only response. One vertical slice — backend and frontend are not split into separate tickets.

**Blocked by:** `01 — Prefactor: payloadAdapter preserves citations/correlation on structured-shape payloads` (`.scratch/payload-adapter-escape-hatch-fix/issues/01-...`), `01 — Visualization Registry: extensible Planner + renderer architecture, with line as the first type` (`.scratch/visualization-registry-line-type/issues/01-...`)

**Dev-environment note (found via `diagnosing-bugs`):** live verification of this whole batch (Diagnostic/Predictive/Prescriptive) was initially blocked by a real, non-obvious local dev-environment bug, not an application bug — `uvicorn --reload` on this Windows machine spawns its actual request-handling worker via Python's `multiprocessing.spawn_main()`, a process whose command line contains no "uvicorn" substring. Every cleanup sweep that filtered on `vite|uvicorn|nest start|concurrently` therefore killed the parent reloader but never the orphaned fork-worker children, which kept answering requests with stale in-memory code across every relaunch this session. Root-caused by isolating a single uvicorn instance outside the npm/concurrently chain (worked correctly every time) versus the full `npm run dev` stack (served stale code), then finding the live `--multiprocessing-fork` process directly via `Get-CimInstance`. Fixed by including `multiprocessing` in the kill-pattern before the final relaunch; not a code change.
